Changelog
[1.0.0] - 2026-11-22
Añadido
Modelo de dominio con herencia y polimorfismo (Entidad, Personaje, Enemigo, Goblin, Orco).
Persistencia en JSON con escritura segura y exportación a JSON/Markdown.
Logging de toda la partida.
Patrones: Factory, Observer, Strategy, Facade.
Interfaz gráfica con tkinter.
Modo consola (--consola) para demos y pruebas.
Paquete instalable (pip install -e .), ejecutable con python -m mazmorra.
Suite de tests con pytest: 222 tests, 74% de cobertura, incluido un test de integración.
